# Paleta de cores — Tema claro

Cores extraídas por amostragem de pixels a partir de `telatarefas.jpeg`. Como a imagem é um JPEG (compressão e anti-aliasing), os valores são aproximados.

| Elemento | Cor aproximada |
|---|---|
| Fundo da página (gradiente azul pastel) | `#B9D8EC` |
| Fundo do card principal (verde-água) | `#BFE2E4` → `#9CC9CF` |
| Cabeçalho "Atividades" | `#9CC9CF` |
| Campo de texto / linha não concluída | `#E4F5FD` |
| Linha concluída / selecionada | `#85B4BA` |
| Checkbox marcado (verde sucesso) | `#7FD9A8` |
| Ícone de arquivo/editar | `#42454A` |
| Botão "+" (fundo) | `#1A2425` com borda `#BCE5DD` |
| Painel de edição (fundo) | `#8FB5BE` |
| Botão Salvar | `#98CFCA` |
| Botão Excluir (borda/texto) | tom coral, próximo de `#E8836E` |
| Texto principal | `#1A2425` (quase preto) |
| Texto secundário/placeholder | `#9099A0` |
